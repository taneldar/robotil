# RoboTil

LEGO WeDo 2.0 роботтарына арналған қазақ тіліндегі блоктық бағдарламалау және AI студиясы.

**Сайт:** https://taneldar.github.io/robotil/

## Не істей алады

- Блоктарды пазлдай жалғап, роботты бағдарламалау: мотор, шам, дыбыс, экран, хабарлар, «Қайтала».
- WeDo 2.0 хабына Bluetooth арқылы тікелей қосылу (Web Bluetooth).
- Датчиктер: қашықтық, еңіс және компьютердің микрофоны.
- **AI үйрету:** бала қимылдарды, жер бетін немесе дыбыстарды мысалдармен үйретеді, ал «AI танығанда», «Егер AI таныса» сияқты блоктар роботты басқарады. AI компьютердің өзінде жұмыс істейді (k-NN), интернет керек емес, деректер ешқайда жіберілмейді.

## Жобалар

- Басты бетте: «Жаңа жоба», «Файлдан ашу», «Майло мысалы» және соңғы жобалар тізімі.
- Жоба (блоктар және үйретілген AI) браузерде сақталады.
- «Жүктеп алу» батырмасы жобаны `.robotil.json` файлы етіп сақтайды — оны басқа компьютерде ашуға немесе мұғалімге жіберуге болады.

## Қалай ашу керек

- Chrome немесе Edge браузерінде сайтты аш (https қажет, Safari мен iPhone Web Bluetooth-ты қолдамайды).
- Компьютерде: `py -m http.server 8000`, сосын `http://localhost:8000`.

## Даму жолы

WeDo 2.0 (оқу орталықтары) → SPIKE Essential → SPIKE Prime (мектептер).
